# 🤖 Atlas AI Agent

**Atlas AI Agent** is a professional-grade cloud bot framework built to handle intelligent interactions using LLMs.

## 🚀 Features

- **Cloud-Native:** Built to be deployed on modern cloud infrastructure.
- **Context Aware:** Designed to handle conversational memory (In-progress).
- **Modular:** Easy to integrate with WhatsApp, Telegram, or Web APIs.

## 🛠 Tech Stack

- **Language:** Python 3.10+
- **AI Engine:** OpenAI GPT-4o
- **Environment:** Linux/WSL2

## ⚙️ Installation

1. Clone the repo: `git clone https://github.com/ThamiBa/atlas-ai-agent.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Set up your `.env` file with your OpenAI API Key.
